### ✨ 项目亮点：基于类复摆模型的不规则刚体转动惯量测量

- **理论原创性**：自主提出可测不规则刚体转动惯量的物理模型，独立推导原理与公式
- **数值仿真**：使用 Matlab + 四阶 Runge-Kutta 法完成数值模拟
- **实验搭建**：自主构建实验装置，解决传统方案中"质量分布不均难以起摆"的痛点
- **适用范围**：**不需要事先确定质心位置**，可测质心不在刚体内部的物体
